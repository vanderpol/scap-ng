## Approved 0.4.1 decisions (implemented)

The two Issue #87 decisions approved on 2026-11-22 are no longer unresolved
holds. Their portable authoring proofs live in
`conformance/cases/core/approved-decisions.assessment.yaml` and the paired
fixture/expected files. The conformance semantic gate enforces the following
without adding OVAL State syntax:

* `variable.value.state_var_ref_guard`: `Test.variable` can replace an original
  State variable reference only when identity is entailed for every compared
  Item. An explicit counterexample is retained and fails closed as not
  losslessly representable; absent source identity remains absent.
* `windows.cmdlet.select_no_wildcard`: explicit unique `object.select` members
  and `select: null` are valid. A `*` member, or a dynamic/unverifiable member,
  is rejected before collection. The rejection is not converted into a
  technical collector ERROR.

These are authoring/semantic gates only. Scanner execution and converter
source-fidelity receipts remain respectively RI #196 and Tools-owned work.
