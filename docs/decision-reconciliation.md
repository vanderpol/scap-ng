## Lessons carried forward

The [35 numbered lesson headings](../research/iterations/001/lessons-learned.md) (number 19 was never present) preserve source-organization failures, fair architecture comparisons, constrained overlays, independent policy identities, typed parameters, build-time dependency resolution, exact-vs-shape reuse, evidence limits, source defect preservation, immutable original evidence and separate scanner conformance.

Later lessons: iteration 002 leaked earlier serialization through reused renderers; iteration 003 restarted native lowering but retained earlier generated trees and misleading entry points. A mixed directory must be classified per file, not called entirely active or entirely obsolete. Root tools can be current helpers even when older renderers also use them. Empty publisher disable lists are explicit data. Runtime results cannot be attached to extensible authored nodes. The unknown-Test corpus failure is now resolved by capability semantics, with a fresh-source CI checkpoint.
