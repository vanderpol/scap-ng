# Candidate license inventory

No project-wide LICENSE/COPYING grant was found in the committed SCAP-NG source
tree during #260 candidate preparation. This file records that gap; it does not
assign a license or broaden rights. The owner must specify the intended source
and specification distribution license before representing the candidate as a
licensed public software release. Existing public repository access alone is
not such a grant.

Original signed SCAP and regression sources retain their publisher notices and
pinned provenance. Their inclusion is not a claim that SCAP-NG owns their
copyright. Vendored schema documentation/notices are preserved unchanged.

The release evidence's dependency inventory records each pinned wheel's exact
filename/hash, metadata version, License/License-Expression fields, classifiers,
and embedded license notice paths/hashes. The offline wheelhouse retains those
notices inside the original unmodified wheels. Dependencies use their own
licenses; this inventory is not a replacement for their license text.

Reproduce the 11-package Linux CPython 3.12 dependency set using
[the hash-pinned lock](../audit/v04-package-acceptance/requirements-linux-py312.lock)
and [operator guide](0.4.0-rc.md). Platform portability and publisher trust are
separate qualification work.
