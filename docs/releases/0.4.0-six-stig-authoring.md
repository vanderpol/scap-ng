# SCAP-NG 0.4.0 — Six-STIG authoring samples

These **pre-alpha authoring samples** demonstrate the current SCAP-NG 0.4.0 Assessment format using six real STIG Benchmarks. They are intended for content review, tooling development and conversion testing—not for production scanning.

Both archives contain **4,001 source documents** covering Red Hat Enterprise Linux 9, Oracle Linux 9, Windows 11, Windows Server 2025, Windows Server DNS, and Apache HTTP Server 2.4 (UNIX). The content includes Benchmarks, Rules, automated and manual Assessments, and reusable shared Assessments.

## What is different in 0.4.0?

- **Closer-to-the-Test expectations:** The common cases use explicit `require.items` and `all_items_must` instead of separate existence and State-matching declarations. Inline Objects inherit their Test's capability.
- **Consistent version references:** All six Benchmarks declare the `0.4.0` Assessment specification required by their referenced automated Assessments. Previous `0.3.0` declarations and source content remain recoverable from the pinned inputs and migration manifests.
- **Preserved complex logic:** Boolean evaluation, source-dependent matching, Variables, Sets, Filters, and manual Assessment alternatives are retained rather than silently simplified.

## Verification and limitations

The six-STIG source set contains **1,375 distinct Tests** and **2,958 Rule-to-Assessment choice links**. YAML and JSON passed native schema validation, graph/reference checks, and parsed-source equivalence. **25,628 generic OVAL result-model comparisons** agreed with the pinned reference model.

**These files are not compiled or signed SCAP-NG 0.4.0 scanner bundles.** Independent scanner execution, capability-specific semantic equivalence, and final distribution-package verification remain open. The **172 uncommon Test requirements** still use explicit source-preserving forms pending more detailed equivalence work.
