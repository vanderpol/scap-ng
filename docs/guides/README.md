# SCAP-NG Guides

**Current scope: 0.4.0 pre-alpha.** These guides explain the current model. They do not declare an interoperable scanner standard or supersede the [specification](../../specification/README.md) and [versioned schemas](../../schema/v0.4.0/README.md).

| Read this | If you want to… |
| --- | --- |
| [Content Author Guide](content-author-guide.md) | Write, review, validate, and package SCAP-NG content. No OVAL background required. |
| [Application Developer Guide](application-developer-guide.md) | Understand the contracts for applications that create, process, or report SCAP-NG content. |
| [Implementation traceability appendix](../developer/IMPLEMENTATION-TRACEABILITY-DRAFT.md) | Inspect a separate, draft requirement/test index for deeper engineering review. Not tool-specific instructions. |

**Source of authority:** The accepted, versioned SCAP-NG specification and schema govern native NG. For SCAP 1.4 migration, use [NIST SP 800-126 Rev. 4](https://csrc.nist.gov/pubs/sp/800/126/r4/final), its [800-126A Rev. 4 annex](https://csrc.nist.gov/pubs/sp/800/126/a/r4/final), [NIST IR 7275 Rev. 4 (XCCDF 1.2)](https://csrc.nist.gov/pubs/ir/7275/r4/upd1/final), and the [SCAP 1.4 component/XSD/Schematron index](https://csrc.nist.gov/Projects/security-content-automation-protocol/scap-releases/scap-1-4). OVAL 5.12.3 XSDs/annotations are the project's pinned OVAL migration baseline. OVAL-to-NG mappings are appendices, not prerequisites.
