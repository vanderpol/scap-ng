# windows.auditeventpolicysubcategories

Proposed documentation; frozen 0.4.1 validation is unchanged.

The `windows.auditeventpolicysubcategories` is used to check the audit event policy settings on a Windows system.

**Contract status: unresolved.** Native collection boundaries, field multiplicity, missing values and error propagation are not established by field descriptions. Legacy source documentation is not a native execution contract.

Occurrences indicate how many times a field may appear within its parent object; a field may separately contain multiple values. Value datatypes are declarations; [advanced constraints](../advanced/windows.auditeventpolicysubcategories.md) retain the validated encodings and any broader schema acceptance.

## Object

The Object is used by an audit event policy subcategories test to define those objects to evaluate based on a specified state.

Therefore, there are no child entities defined.
