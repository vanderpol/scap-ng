# independent.unknown

Proposed documentation; frozen 0.4.0 validation is unchanged.

An `independent.unknown` acts as a placeholder for tests whose implementation is unknown.

**Contract status: unresolved.** Native collection boundaries, field multiplicity, missing values and error propagation are not established by field descriptions. Legacy source documentation is not a native execution contract.

Occurrences indicate how many times a field may appear within its parent object; a field may separately contain multiple values. Value datatypes are declarations; [advanced constraints](../advanced/independent.unknown.md) retain the validated encodings and any broader schema acceptance.
