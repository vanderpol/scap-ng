# Experimental/deferred capability mappings

These mappings are retained research artifacts and are **not** part of the
supported SCAP-NG 0.2.0 content-development capability baseline.

Current experimental mappings:

- `esx.host_account`
- `esx.host_advancedsetting`
- `esx.host_service`
- `esx.host_vib`

Further ESX adoption is deferred pending upstream/original-implementer guidance.
The two OVAL 6.0 Kubernetes Tests are also deferred and have no native 0.2.0
mapping here.

Experimental mappings remain versioned and regression-tested as research
evidence, but tools SHALL NOT count them as supported 0.2.0 capabilities.
