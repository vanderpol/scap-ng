# Capability mappings

- [supported](supported/README.md) contains the version-local mapping records
  enumerated by `../capability-scope.json`.
- [experimental](experimental/README.md) contains explicitly deferred
  research mappings.

Capability metadata defines selectors, fields, datatypes and source lineage.
It does **not** establish that a particular scanner implements the capability
or has passed acquisition/runtime conformance.
