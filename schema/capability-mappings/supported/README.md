# Versioned supported mapping catalog

The JSON mapping files in this directory preserve the effective 0.4 source
contract, including OVAL provenance and native selectors. Refer to
[`capability-scope.json`](../../capability-scope.json) for the authoritative
supported/experimental scope classification; file placement alone is not a
runtime implementation guarantee.

The mappings are copied byte-for-byte from the frozen source. Do not edit them
to reconcile converter or scanner behavior without renewed owner review.
