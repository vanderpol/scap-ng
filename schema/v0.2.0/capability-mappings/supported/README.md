# Supported SCAP-NG 0.2.0 capability mappings

These 100 reviewed, non-deprecated OVAL 5.12.3-derived mappings are the
supported SCAP-NG 0.2.0 capability baseline. Their mapping definitions remain
single-source under `schema/v0.1.0/capability-mappings/` because their source
capability semantics did not change between 0.1.0 and 0.2.0.

When used by a 0.2.0 Assessment, generators and validators resolve these mappings
against the 0.2.0 shared authoring/result contracts. The 0.2.0 promotion regression
enumerates this list, verifies the count and generates every capability against
0.2.0 schema IDs.

This is intentional inheritance, not fallback: a missing or unknown capability
fails validation.
