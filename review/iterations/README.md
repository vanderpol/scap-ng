# SCAP-NG review iterations

This directory preserves earlier coherent review sets after they are superseded by `../current/`.

The purpose is traceability, not parallel authority.

Each preserved iteration should contain or link to:

- the design/specification state presented for review;
- the schemas and examples that accompanied it;
- the Board questions active at that time;
- the validation/equivalence evidence available at that time;
- a short note explaining why the iteration was superseded.

Only `../current/` is the current external review target.

Historical research artifacts that were never a coherent external review set do not belong here; they remain in the repository's archive/research history.
