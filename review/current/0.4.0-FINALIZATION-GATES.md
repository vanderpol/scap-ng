## Order of operations

1. Lock grammar and its validators; disallow silent defaults and ambiguous duplicate capability declarations.
2. Validate the full six-STIG source closure under the *actual* grammar and identify all remaining legacy tokens. Rebuild if needed.
3. Complete native compiler and semantic boundary cases, not just parsed-source reconstruction.
4. Migrate the editor to exactly that pinned source/schema; verify imports, structured edits and downloads.
5. Review coverage and publish a single concise 0.4.0 release packet, including failed/unresolved gates.

**Do not mark 0.4.0 final** merely because a workflow is green, a preview ZIP exists, or metadata is copied. An archive of OVAL annotations is not a reviewed NG-native scanner implementation guide.
