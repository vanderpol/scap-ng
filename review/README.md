# SCAP-NG review records

The current external-review entry point is **[the OVAL Board review page](../board/README.md)**.

This directory stores compact supporting review records:

- [`current/`](current/README.md) — supplemental current-review summaries that do not belong in the Board landing page.
- [`iterations/`](iterations/README.md) — frozen earlier review sets retained for traceability.

Review lifecycle and artifact-retention rules are maintained once in [`MAINTAINING.md`](../MAINTAINING.md). This directory does not redefine current project status, architecture, or acceptance criteria.
