# RHEL 9 five-rule SCAP-NG source sample

Five Rules from the signed RHEL 9 V2R9 STIG SCAP 1.4 benchmark. Each Rule has:

- Rule policy;
- a procedure-only Manual Assessment preserving the source Check Text;
- a Stage-1 lossless Automated Assessment preserving source OVAL behavior.

The files are design-review source, not a frozen schema. Historical SCAP identifiers are comments where useful and are not scanner semantics.
