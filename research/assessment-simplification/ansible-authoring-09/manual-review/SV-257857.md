# Manual automation candidate — SV-257857

> **RESEARCH ONLY — no automation claim has been made.**

Requirement: removable-media file systems must use the `noexec` mount option.

The current manual procedure tells the reviewer to inspect `/etc/fstab`, but
the hard part is not parsing mount options. The hard part is deciding which
file systems are **used with removable media**.

Therefore this should **not** be classified as a shellcommand conversion merely
because a command could parse `/etc/fstab`.

Questions that must be answered before automation is legitimate:

1. Can the scanner reliably identify removable-media-backed file systems from
   typed system data?
2. Is the requirement about configured mounts, active mounts, or both?
3. How are transient/removable devices that are not present during assessment
   handled?
4. Does DISA intend organizationally approved removable storage to be supplied
   as input?
5. Can the answer be obtained portably without scanner-specific heuristics?

Provisional classification: **manual / needs domain-model research**, not
`shellcommand`.
