These are candidate research questions, not requests to suspend work. Further bounded experiments can proceed without voting. Exact type/field names for new collectors need scanner implementer input later.

Rejected approaches:

- Numeric permission `mode <= 0740`: counterexample 0604; preserve individually addressable permission booleans.
- Effective Apache value alone: accepts absent explicit directives or hides overridden occurrences.
- Generic ACL list as effective Windows rights: ignores access token and ACE order.
- Flattened multi-field arrays or positional zipping: can combine unrelated records.
- Silently fixing source audit b64 branches, duration truncation or missing content: a correction is not lossless simplification.
- Shell/PowerShell filesystem recursion: violates native acquisition/traversal boundary.
- Runtime inputs controlling macro rows/tests or script text: violates Organizational Input constraints.
- Universal policy-aware `compliant` collector: hides author decisions and evidence.
- Removing rare supported capabilities, complement/filter behavior or multiple variable instances: no supporting evidence.

Deferred research issues retained from the project: assessment-native informational/notapplicable outcomes, reference-scanner sequencing, complete early-termination proof and compiler/schema stabilization. They are outside this research's schema scope.
