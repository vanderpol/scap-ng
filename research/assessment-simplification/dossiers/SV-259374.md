> Log on to the DNS server using the Domain Admin or Enterprise Admin account or Local Administrator account. Use "ipconfig /all" to identify all network adapters. or Locate the "Network Internet Access" icon, right-click on it, and select "Open Network & Sharing Center". Click "Change adapter settings". Right-click on the Ethernet and click "Properties". Select "Internet Protocol Version 4 (TCP/IPv4)" and click "Properties". Verify the "Use the following IP address" is selected, with an IP address, subnet mask, and default gateway assigned. If the "Use the following IP address" is not selected with a configured IP address, subnet mask, and default gateway, this is a finding.

## Complete baseline dependency explanation

Five Tests OR a Variable count==0 or four all-value command predicates. Six Objects, five Variables and three States. Get-NetAdapter ifIndex drives separate address, prefix, gateway and SuffixOrigin queries; exceptions are caught without output. Four States/Tests require nonempty per-output entities; source uses SuffixOrigin=Manual as static signal.

### Necessary semantics versus representation overhead

A row carrying interface/address identity is safer to review than separate arrays. This does not prove the original variable-instance machinery loses correlation. PrefixOrigin/DHCP and SuffixOrigin are not automatically interchangeable. Requiring every offline adapter changes source scope.

Object status/completeness, Item and entity existence, item/state/variable quantifiers, Boolean nesting and acquisition scope are necessary semantics. Source comment/title, separate serialization wrappers and repeated command/regex construction are not independent security requirements. Named shared Objects and Variables SHALL remain referenceable.

## Methods investigated

A: fixed batched query retaining source Up and SuffixOrigin policy with one record per interface/address plus gateway relation. B: typed network capability with explicit static-address facts; replacing the static signal is a separate policy decision. Existing variable.value can remove the count-wrapper Object without new language.

[Complete after sketch](../proposals/interface-records.proposal.yaml) — all invented fields use the [experimental contract](../FEATURES.md). This sketch shows the proposed method, not a deployable lossless conversion; applicability/bindings remain unchanged unless separately reviewed. A no-change baseline remains valid.

## Cases and falsification

Zero online; one interface missing gateway; multiple IPv4 addresses; prefix0/32 versus merely nonempty; gateway on other interface; Manual suffix but DHCP facts differ; IPv6-only; offline adapter; query exception; unknown status. Explicit duplicates need an address key rather than unique ifIndex alone.

Executed cases are in [test_semantics.py](../experiments/test_semantics.py) and [results](../evidence/test-results.txt). Additional acquisition/OS cases above are specified, not executed. Per-record missing/error/unknown/multiple-match/partial-collection fixtures are synthetic language experiments, not evidence that source collectors behave that way.
