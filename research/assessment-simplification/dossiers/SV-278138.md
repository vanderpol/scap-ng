On domain controllers, protect AD database/log files so SYSTEM and Administrators have full rights and others have no effective rights. Domain-controller detection remains separate applicability.

### Original Check Text

Exact XML serialization and complete selectors/links are retained in [source-rule.xml](../evidence/ms_windows_server_2025/SV-278138/source-rule.xml). Text below is the inherited generated procedure, with presentation whitespace normalized:

> This applies to domain controllers. It is not applicable for other systems. Run "Regedit". Navigate to "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\NTDS\Parameters". Note the directory locations in the values for: Database log files path DSA Database file By default, they will be \Windows\NTDS. If the locations are different, run the following for each: Open "command prompt (Admin)". Navigate to the NTDS directory (\Windows\NTDS by default). Run "icacls *.*". If the permissions on each file are not as restrictive as the following, this is a finding: NT AUTHORITY\SYSTEM:(I)(F) BUILTIN\Administrators:(I)(F) (I) - permission inherited from parent container (F) - full access

### Necessary semantics versus representation overhead

A DACL ACE allowlist is not an effective-rights collector. Deny/allow order, inheritance, token group membership and unknown principals cannot be erased. Collapsing per-directory existence into one global some permits an empty/missing directory to hide behind another.

Object status/completeness, Item and entity existence, item/state/variable quantifiers, Boolean nesting and acquisition scope are necessary semantics. Source comment/title, separate serialization wrappers and repeated command/regex construction are not independent security requirements. Named shared Objects and Variables SHALL remain referenceable.

## Methods investigated

A: finite directory×principal authoring table expanded to existing windows.fileeffectiverights53 Tests, preserving Filters and per-directory existence. B: keyed effective-right records reused by three predicates, if collection behavior and identity universe can be shown equivalent. No new effective rights semantics proposed.

[Complete after sketch](../proposals/ad-file-rights.proposal.yaml) — all invented fields use the [experimental contract](../FEATURES.md). This sketch shows the proposed method, not a deployable lossless conversion; applicability/bindings remain unchanged unless separately reviewed. A no-change baseline remains valid.

## Cases and falsification

Two directories one empty; non-DC; unknown SID; inherited allow plus deny; local/domain group; inaccessible registry or file; zero-right stranger filtered versus stranger with one right; directory/file distinction; junction. Synthetic ACE order test is a counterexample only, not Windows evaluator conformance.

Executed cases are in [test_semantics.py](../experiments/test_semantics.py) and [results](../evidence/test-results.txt). Additional acquisition/OS cases above are specified, not executed. Per-record missing/error/unknown/multiple-match/partial-collection fixtures are synthetic language experiments, not evidence that source collectors behave that way.
