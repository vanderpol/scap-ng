# New-method decision candidates, version 1

Unpublished experimental candidates. These differ from AS-RD table/acquisition
questions; old versions remain unchanged. No vote or second review surface is
opened. Promotion requires coordinated `review/current/` navigation and separate
immutable versioned yes/no Discussions, 👍 Yes / 👎 No, with eligibility/quorum/
disposition rules. A passing model test does not ratify a language feature.

provider versioning/consistency; the relationship between inline and named States;
proof/witness retention versus collection completeness; permitted domain-specific
coverage semantics; author editor/controlled-language usability; six-state and
advanced feature coverage. None requires stopping the current bounded research.
