# Iteration 003 Focused Examples

This directory contains small, reviewable examples for individual SCAP-NG
semantics and conversion cases.

Examples are intentionally separate from complete benchmark source trees.

Use this area for cases such as:

- simple automated assessment;
- manual assessment;
- selectable check alternatives;
- applicability indirection;
- profile deltas;
- parameter binding;
- existence/cardinality semantics;
- complex Boolean assessment logic.
