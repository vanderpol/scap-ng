# Policy-structure review examples

These files are deliberately small review prototypes for Iteration 002. They
exercise policy concepts before schema lock-in.

They demonstrate:

- a Benchmark with real version semantics;
- stable Rule identity separated from revision;
- meaningful multi-Rule/nested Group structure;
- a publisher Profile;
- a publisher-defined Parameter overridden through Tailoring;
- an unresolved organizational Parameter supplied at assessment time;
- separation between Assessment Method and Assessment Request;
- expected-state-only use of externally supplied values;
- provenance requirements that distinguish Tailoring from Organizational Input.

The two `example.*` Rules are illustrative and are not asserted to be DISA
STIG requirements. `RHEL-09-212030` remains the existing real-source review
example.
