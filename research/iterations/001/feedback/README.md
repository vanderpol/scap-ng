# Iteration 001 Feedback

This directory preserves external review evidence and converts review comments into explicit research requirements.

## Workflow

1. Provide reviewers with `questionnaire.md` and the iteration prototypes.
2. Ask reviewers to return `response-template.md` or another document that preserves the stable question IDs.
3. Store returned files unchanged under `responses/`.
4. Record accepted, rejected, deferred, or superseded conclusions in `decision-register.md`.
5. Use the decision register as an input to the next iteration or eventual specification.

Do not rewrite original reviewer responses after receipt. Corrections or follow-ups should be stored as additional files so the evidence trail remains intact.
