# Reviewer Responses

Store returned OVAL Board, NIST, DISA, vendor, or other stakeholder feedback here **without rewriting the original response**.

Suggested filename:

`YYYY-MM-DD-organization-reviewer-or-group.md`

If feedback is received in another format, preserve the original file when practical and add a companion Markdown note only when needed for indexing.

Stable question IDs from `../questionnaire.md` should be retained wherever possible.
